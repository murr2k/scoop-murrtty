# murrtty for Scoop

A [Scoop](https://scoop.sh) bucket for [murrtty](https://murrtty.org), a
native Windows terminal forked from Ghostty.

```powershell
scoop bucket add murrtty https://github.com/murr2k/scoop-murrtty
scoop install murrtty/murrtty
```

That puts `murrtty` on your PATH and in the Start menu, for x64 or ARM64.
`scoop update murrtty` takes newer releases.

murrtty is a preview and isn't code signed yet. Its source, releases and
issue tracker are at [github.com/murr2k/murrtty](https://github.com/murr2k/murrtty).
murrtty is not affiliated with or endorsed by the Ghostty project.
